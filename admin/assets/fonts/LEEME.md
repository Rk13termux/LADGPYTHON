# Tipografías del panel

El panel usa las mismas familias que el sitio: **Space Grotesk** (títulos),
**Inter** (texto) y **Fira Code** (código).

Si quieres que se apliquen, deja aquí los archivos con estos nombres exactos:

```
admin/assets/fonts/
├── SpaceGrotesk-Bold.ttf
├── SpaceGrotesk-SemiBold.ttf
├── Inter-Regular.ttf
├── Inter-Medium.ttf
├── FiraCode-Regular.ttf
└── FiraCode-Medium.ttf
```

Los `.ttf` están excluidos de Git (son binarios y conllevan licencia propia).
Sin ellos la aplicación arranca igual, usando las tipografías del sistema.
